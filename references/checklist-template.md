| T12 | 重启持久性（若请求） | 记录允许的重启层级，固定 selector，正常退出重开；不关闭保护 | 前后 PID/启动日志、UDP/TCP53、系统 DNS 覆写及接管、实际出口、PF 正反对照；整机重启另列 | |

教程中的系统更新、BBR、2FA 等另加任务卡。出现动态码输入框不能代替正确码登录；禁止自动关闭 2FA 作为故障处理。

## 条件诊断记录

按 [排障判据 C](troubleshooting.md) 填写，仅故障排查需要此表。一个新时间窗对应一条记录，不能拿昨天失败替代今天结果。

路径字段应包括来源网络、核心/实例、入口方式（显式代理/TUN）、目标、实际拨号接口与 selector；据此说明哪些结果可比较。恢复验收前确定本次样本数、观察窗口、超时与 UDP 适用性；达到已定范围就交付，不无限追加测试，也不把成功次数换算成长期保证。

| UTC 开始/结束 | 源/实际路径、目标角色 | 运行配置摘要/期间变更 | TCP / TLS / 代理认证 / 出口 / UDP | 同窗正对照与双端关联 | 结论与未知项 |
|---|---|---|---|---|---|
| | | | | | |

每项变更实验再记录：假设 → 可区分的预期结果 → 影响范围 → 实际生效证据 → 结束条件 → 全部原值恢复与临时进程清理。结果不支持继续区分时停止，时间窗改变或准备外发材料时先复测原基线。
