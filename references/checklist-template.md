## 任务卡

| ID | 任务与适用条件 | 执行动作 | 测试/验收证据 | 状态 |
|---|---|---|---|---|
| T1 | 核对与备份 | 真实节点/SSH、schema、当前 GUI、源配置、有效管理器；一致数据库快照 | 路径、摘要、权限、变更前状态 | |
| T2 | 服务端（仅适用时） | 环境/BBR、入站/客户端/flow、目标 TLS、管理/防火墙 | 配置校验与真实认证、出口；重启未做则明确未测 | |
| T3 | GUI 整合 | 原生节点、单一手动组、GLOBAL、国内直连、持久选择 | 每个 GUI 选择与运行 selector 一致 | |
| T4 | 实际网络 | 两个独立 IP 来源、TUN 路径、UDP、国内直连 | 每个出口与预期一致；不要用延迟值代替 | |
| T5 | DNS | 完整覆写、显式 policy 顺序、UDP/TCP 53、DoH 经选择组 | 源/持久/生成一致、实际解析与出站证据 | |
| T6 | 故障隔离 | 仅测试副本令选中节点不可达、其余保留；rule/global | 连接和受保护 DNS 阻断、选择不变；临时进程已停 | |
| T7 | Claude Desktop（若安装） | 原生固定代理，不用 PAC；保留原账号/provider | 新启动日志、普通模式、观察到的连接链；不发送聊天 | |
| T8 | Claude CLI（若安装/将使用） | 用户设置中的大小写 HTTP(S)_PROXY、NO_PROXY | 未安装则只标已预置；实际进程未测不能勾通过 | |
| T9 | 独立路径与收尾 | 按用户范围检查系统代理、更新器、外部浏览器、IPv6、其他 VPN | 未覆盖路径、无断网锁边界、抓包/核心清理 | |

教程中的系统更新、BBR、2FA 等另加任务卡。出现动态码输入框不能代替正确码登录；禁止自动关闭 2FA 作为故障处理。
